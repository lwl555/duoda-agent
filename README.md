# 多答 Agent

小林科技出的 AI Agent 安卓客户端。

## 下载

点右边 Releases → 最新一版 → 下 `duoda-x.y.z-arm64.apk`。

或者直接：https://github.com/lwl555/duoda-agent/releases/latest

## 装的时候注意

- 只支持 64 位 ARM（现在的手机基本都是）。
- 覆盖安装即可，模型配置、技能、聊天记录都在。
- 如果系统提示「未知来源」，在设置里允许一次就行。

## 更新

App 启动会自动查新版本，也能在 设置 → 关于 里手动查。有新版本时 App 内会弹公告，点「去看看」就是这里。
